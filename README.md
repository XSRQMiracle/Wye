# Wye（同频）

Play system audio on multiple headphones/speakers in sync — drift-corrected, latency-aligned. macOS first, Windows next.

把电脑正在播放的声音**同步**送到多个输出设备：两个人各戴一副蓝牙耳机一起看视频，或者电脑扬声器加一个蓝牙音箱。
长时间播放不漂移、不爆音，设备之间的延迟自动对齐（可用麦克风一键校准），常驻菜单栏，勾选设备即可使用。

## 当前状态

开发中，还不能日常使用。

## 系统要求（规划）

- macOS 14.4 或更新（在 macOS 26/27 上测试），需要「系统音频录制」权限；不需要安装虚拟声卡
- Windows 10 2004 / Windows 11（规划中）
